# 网申轻填 · 本地简历助手

**导入一次简历，选择需要的内容，再填入不同公司的网申表单。**

网申轻填是一款 Chrome / Edge 浏览器扩展。它在本机读取简历，整理基本信息、教育、实习和项目经历，识别当前网页的输入字段，让你预览、选择和修改之后，一键填写或复制。

无需服务器、账号、API Key 或付费模型。当前版本：**v0.1.2**。

[下载插件安装包](downloads/resume-fill-v0.1.2.zip?raw=true) · [版本记录](CHANGELOG.md) · [测试说明](TESTING.md)

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 本地导入简历 | 支持文字型 PDF、Word `.docx`、TXT、MD 和插件导出的 JSON |
| 结构化资料库 | 保存基本信息，以及多段教育、实习 / 工作、项目经历；支持自定义资料 |
| 识别当前网页 | 读取字段名称、提示和所属经历，给出可核对的资料匹配建议 |
| 选择性预填 | 按项勾选、切换资料来源，或直接编辑这次准备填入的内容 |
| 一键填写 / 复制 | 批量填入已选内容，也可逐项复制或批量复制 |
| 保留已有内容 | 默认跳过网页已有值，允许用户明确选择覆盖 |
| 检查填写结果 | 回读控件值，提示已填入、已跳过或需要手动处理 |
| 备份与恢复 | 导出 / 导入 JSON；支持清除插件保存在本机的资料 |
| 内置练习表单 | 使用虚构资料练习识别、预览、复制与填写，无需真实投递 |

插件不会点击网站的“下一步”或“提交”。

## 安装到 Chrome / Edge

当前通过“加载已解压的扩展程序”安装，尚未上架扩展商店。建议使用最新稳定版 Chrome 或 Edge，最低 Chromium 版本为 122。

1. [下载 v0.1.2 安装包](downloads/resume-fill-v0.1.2.zip?raw=true)，完整解压到一个固定文件夹。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择直接包含 `manifest.json` 的解压目录。
5. 将 **网申轻填 · 本地简历助手** 固定到浏览器工具栏。

如果通过仓库右上角 **Code → Download ZIP** 下载的是整个源码仓库，解压后请选择仓库里的 **`src/` 文件夹**；安装包与源码包的目录不同。

## 使用流程

### 1. 导入并核对资料

打开招聘网站，点击工具栏上的插件图标。在侧栏 **我的资料** 中上传简历，或展开“也可以粘贴简历文字”。

检查姓名、邮箱、联系方式，以及每段经历的公司 / 学校、职位、起止时间和描述。支持添加、编辑和移除经历；项目可以单独记录所属公司。最后点击 **确认并保存资料**。

本地规则可能无法准确拆分复杂排版，请务必核对。没有明确提供的信息会留空，不会补写经历、GPA 或证书。

### 2. 识别当前网申页面

先在网站中展开要填写的编辑区域，然后切换到 **网页预填**，点击 **识别网页**。

如果出现“允许访问 [网站名称]”，点击按钮并在浏览器提示中确认。插件仅为当前站点申请访问权限，授权后重新读取本页。

### 3. 选择这次要填什么

识别后，每项都会显示：网页字段、建议资料及准备填入的内容。你可以：

- 勾选 / 取消需要填写的字段。
- 从下拉列表换成另一段教育、实习或项目资料。
- 直接修改预填文字；这只影响本次填写，不修改保存的资料库。
- 对不支持的复杂控件，点击 **复制此项**，到网站上手动粘贴或选择。

默认保留网页已有内容。需要替换时，先勾选 **允许覆盖网页已有内容**，再选择对应字段。

### 4. 填入并检查

点击 **填入已选**。核对插件的结果提示以及网站上的实际内容，再自行保存、翻页或提交。

进入下一页、添加了新经历、刷新页面或切换了网站后，请重新识别。旧预览与原页面文档绑定，避免把旧选择填进新页面。

## 先用虚构资料体验

1. 点击侧栏底部 **打开练习表单**。
2. 点击 **载入示例资料**，然后 **确认并保存资料**。
3. 切换到 **网页预填**，识别练习表单，勾选并试填。

示例资料全部虚构，仅用于练习。导入自己的简历时会提示替换现有资料，建议先导出需要保留的备份。

## 支持范围与限制

| 内容 / 控件 | 当前支持情况 |
| --- | --- |
| PDF | 按页面坐标恢复文字顺序；支持常见单栏及部分双栏；扫描件不做 OCR |
| Word | 支持 `.docx`；旧 `.doc` 请先另存为 `.docx` |
| 文件限制 | 最大 20 MB；PDF 最多 30 页，45 秒读取超时 |
| 普通输入框、多行文本 | 支持，并在填写后回读检查 |
| 原生下拉框、单选组 | 只在候选选项有唯一明确匹配时填写 |
| 搜索下拉框、地区级联等自定义控件 | 提供资料和复制入口，需要用户手动选择 |
| 复选框、隐私声明 | 用户自行确认，不自动勾选 |
| iframe、Shadow DOM | 尝试同源 iframe 与开放 Shadow DOM；跨域表单需手动处理 |
| 验证码、文件上传、提交 | 用户操作 |

目前没有对所有公司的招聘网站完成兼容验证。网页回读成功也不代表网站后端已保存，应检查页面校验及保存结果。网站本身若有自动保存功能，填入后会按该网站的逻辑处理。

## 隐私与权限

- 简历解析、字段匹配和资料保存均在本机完成，插件没有服务端，不向云端上传简历。
- 保存的资料位于当前浏览器配置的 `chrome.storage.local`，不使用云同步；本地保存本身不等于加密。
- `tabs` 用于识别当前标签页的网址 / 标题；`activeTab` 与 `scripting` 用于用户主动操作后的页面读取和填写。
- 网站访问权限按当前站点申请，可在扩展详情中撤销；不会自动申请访问所有网站。
- `sidePanel` 用于侧栏，`clipboardWrite` 用于用户点击后的复制。
- **导出备份**生成明文个人资料 JSON；请自行妥善保存。**清除本机资料**不会清除已导出的文件、剪贴板或已填进网站的内容。

本仓库只包含通用源码、虚构示例和安装包，不包含个人简历或真实个人档案。

## 更新插件

1. 在旧版中导出资料备份。
2. 将新版文件覆盖到原来加载的插件目录。
3. 在浏览器扩展管理页点击插件的 **重新加载**。
4. 关闭旧侧栏，刷新招聘页面后重新打开。

保持原插件目录及浏览器配置通常可以沿用资料，无须先卸载。若更新了抽取规则，请重新上传简历并校对保存，以替换旧的抽取结果。

## 常见问题

**识别到 0 个字段。**

先进入或展开网站的编辑区，再识别。插件读取已经存在的可编辑控件，不会自动点击网站的编辑按钮。跨域内嵌页面或特殊控件可能需要复制后手动填写。

**没有权限访问网页。**

在目标网页点击插件图标，再识别并点击带网站名称的授权按钮。浏览器设置页、扩展商店等受保护页面不能操作；本地文件还需在扩展详情中允许访问文件网址。

**修改资料后预填没更新。**

先确认保存，再重新识别网页。

**内容看起来填进去了，但网站仍提示必填。**

网站可能使用了自定义控件，未接受普通输入。请复制后手动输入或选择网站候选项，并检查保存结果。

## 开发与测试

原生 JavaScript / HTML / CSS，Manifest V3，无运行时服务器，无需构建即可加载 `src/`。

```text
src/
  manifest.json       扩展配置
  background.js       侧栏入口
  index.html          资料与预填界面
  app.js              界面与交互
  content.js          网页扫描、填写与回读
  lib/profile.js      资料校验、解析、字段匹配
  lib/importer.js     本地 PDF / DOCX / 文本读取
  lib/page-access.js  网站访问与目标文档检查
  vendor/             本地 PDF.js、JSZip 与许可证
tests/                规则、文件导入和浏览器回归测试
downloads/            可直接解压安装的插件 ZIP
```

运行纯规则测试：

```bash
node --test tests/*.test.mjs
```

浏览器测试需要 Playwright、pdf-lib、JSZip 与 Chromium 系浏览器，仅供开发测试使用：

```bash
npm install --no-save playwright pdf-lib jszip
```

可以通过 `BROWSER_PATH` 指定浏览器程序，通过 `NODE_MODULES_PATH` 指定现有测试依赖目录。详见 [TESTING.md](TESTING.md)。
